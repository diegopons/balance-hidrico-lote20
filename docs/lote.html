Qué hacer con esto

El guardado se hace con un commit, por eso son dos pasos

  1. Copiá el GeoJSON o descargá el archivo.
  2. En el repositorio, abrí aoi/lote.geojson (o crealo con Add file → Create new file si todavía no existe), pegá el contenido y confirmá con Commit changes.
  3. Si todavía no lo hiciste, cambiá en config.yaml la línea del lote a shapefile: "aoi/lote.geojson".
  4. Corré el flujo desde Actions → Run workflow. Al detectar que cambió el polígono, el balance se reinicia solo.
Cambiar el lote invalida el balance acumulado del anterior: el agua útil, la profundidad de raíz y la serie histórica corresponden a otra superficie. El sistema lo detecta por su cuenta y empieza de cero, pero conviene saber que la serie previa queda en el CSV y no se borra.
Las coordenadas se expresan en latitud y longitud (EPSG:4326), que es lo que esperan tanto Copernicus como el resto del sistema. La superficie se calcula sobre el elipsoide WGS84.
